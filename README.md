# AI Resume Analyzer

A Streamlit-based web application that analyzes resumes against job descriptions and provides a match score, missing skills, and improvement suggestions.

## 🔥 Features
- Upload PDF resume
- Extracts text using PyPDF2
- Calculates match score based on keyword matching
- Identifies missing skills
- Provides improvement suggestions

## 🛠 Tech Stack
- Python
- Streamlit
- PyPDF2
- Basic NLP (keyword matching)

## ▶️ How to Run Locally
pip install -r requirements.txt  
streamlit run app.py
